## 왜 이 글을 썼나

이 사이트에는 한국어로 글을 쓰면 GitHub Actions가 Google Gemini API를 이용해
자동으로 영어 버전을 만들어주는 파이프라인이 붙어 있습니다. 실제로 잘
동작하는지 확인하기 위해 짧은 테스트 글을 하나 올려봅니다.

## 확인하고 싶은 것

- 한국어 원문을 push하면 `content-en` 에 영어 번역본이 자동으로 커밋되는지
- 번역된 글이 `/en/writing/` 목록과 상세 페이지에 정상적으로 노출되는지
- 방금 만든 글이라 목록에 "New" 배지가 함께 붙는지

## 마무리

이 글은 확인 목적의 테스트 글이라 나중에 지우거나 다른 내용으로 바꿔도
괜찮습니다.
